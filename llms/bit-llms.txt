# Bit

> Bit (teambit) is the platform for the modular web — a build system and cloud for component-driven development. Teams create, version, and share reusable components as standard npm packages across frameworks (React, Vue, Angular, Node.js, Next.js), with independent build, test, and CI/CD per component. Every Bit feature is API-first (aspect programmatic APIs composing into a GraphQL API), and Bit ships a built-in MCP server plus a published Claude Agent Skill for AI-agent workflows.

## APIs
- [Bit Cloud GraphQL API](https://api.v2.bit.cloud/graphql): API-first endpoint powering the CLI, UI, and Bit Cloud (introspection disabled in production).

## Tools
- [Bit CLI command surface](cli/bit-cli.yml): install via `npm i -g @teambit/bvm && bvm install`.
- [Built-in MCP server](mcp/bit-mcp.yml): `bit mcp-server start`; hosted Bit Cloud MCP auto-wired by `bit init`.
- [Agent Skill (provider-published)](skills/bit-cli.md): official Claude Code skill from teambit/bit.
